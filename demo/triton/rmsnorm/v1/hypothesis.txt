Hypothesis: Process 4 rows per block (ROWS_PER_BLOCK=4) to reduce redundant gamma loads from global memory
Rationale : v0 NCU shows Memory SOL=86.0%, Long Scoreboard stall=92.05% indicating memory-bound.
